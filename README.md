# GREEN-API Chat

Веб-чат для отправки и получения сообщений WhatsApp через [GREEN-API](https://green-api.com/).

> Проект в разработке.

## Возможности

- Вход по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`)
- Создание нового чата по номеру телефона получателя
- Отправка текстовых сообщений
- Получение входящих текстовых сообщений в реальном времени

## Стек

- React 19
- TypeScript
- Vite
- Tailwind CSS

## Как запустить локально

Требуется Node.js 20+.

```bash
git clone https://github.com/AlyaEngineer/green-api-chat.git
cd green-api-chat
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173.
